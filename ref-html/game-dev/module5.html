01

The Digital Workspace

Every 2D animation tool — Synfig, Blender Grease Pencil, Adobe Animate, Toon Boom, even After Effects — is built on three core concepts that never change regardless of software: layers, keyframes, and the timeline. Master these in one tool and you can read any other tool's interface within minutes.

The typical workspace is divided into three zones: a canvas where you see and draw your frames, a layer panel where you manage which elements are on which layers, and a timeline where you place and manipulate keyframes over time. Everything else — brushes, cameras, effects — is built on top of these three.

Mental Model
Think of layers like sheets of transparent acetate stacked on a light table — the classic setup from hand-drawn animation studios. Each sheet can be moved, redrawn, or replaced without disturbing what's on the other sheets. The timeline tells you when to show each combination of sheets.
02

Layers — The Stack

Layers are the fundamental unit of organisation in any digital animation project. Each layer contains one element — a character part, a background, a label — and layers are rendered in order from bottom to top. What's on top covers what's below.

Good layer discipline separates professional from amateur work. Professionals keep every independently moving element on its own layer, name them clearly, and group related layers into folders. Bad layer hygiene — everything on one layer, unnamed, flattened — makes later editing painful or impossible.

Raster vs Vector Layers
Most tools offer both. Raster layers contain pixel drawings — great for textured brushwork, but resolution-dependent. Vector layers contain mathematical paths — infinitely scalable, better for rigging and clean motion-graphics work. For educational YouTube animation, vector layers are usually the better choice for anything that will move.
03

The Timeline & Keyframes

The timeline is the horizontal axis of time. Each column is one frame. You place keyframes at moments where a property has a specific value — position, rotation, scale, opacity. The software then interpolates all the frames between keyframes automatically.

A keyframe is not a drawing — it is a recorded value. At frame 1, X-position = 0. At frame 24, X-position = 400. The software calculates positions 2 through 23 based on the interpolation curve you choose. This is the entire mechanism of tween-based animation.

Notice the key distinction: keyframes on different tracks are independent. You can keyframe the position of a shape without keyframing its colour, and vice versa. This granularity is what makes software animation so powerful — every property of every layer can have its own independent animation curve.

05

Onion Skinning

Onion skinning is a technique borrowed directly from hand-drawn animation on physical light tables, where animators could see through several sheets of paper to trace and align drawings. In digital tools, it works the same way: you see ghost images of the previous and next frames while drawing the current one.

This is how animators ensure consistent arcs, smooth spacing, and correct proportions across frames without having to flip back and forth constantly. The onion skin frames are shown at reduced opacity — typically a different colour for "before" frames and "after" frames so you can tell them apart at a glance.

06

Manual vs. Tweened In-Betweens

Software interpolation — tweening — is powerful but dumb. It finds the mathematically shortest path between two keyframe values. For a position, that's a straight line. For a rotation, that's the shortest angular direction. Real motion almost never takes the shortest path.

This is why professional animators don't rely purely on auto-tweens for character work. They add intermediate keyframes to define arcs, override linear paths, and inject personality. The tween handles spacing; the animator handles shape.

When to Tween, When to Hand-Key
Auto-tween works well for:
Simple object transitions
Diagram reveals & label slides
Opacity fades
Camera moves
Scale pulses
Hand-key when you need:
Organic arcs (character limbs)
Weight and impact hits
Personality and timing nuance
Complex overlapping motion
Lip sync phoneme timing
